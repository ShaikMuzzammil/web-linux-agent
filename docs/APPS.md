# WebLinuxOS v4 — App Guide

## System Apps
| App | Description |
|-----|-------------|
| Settings | 15-section system settings (Bluetooth, Background, Appearance, Notifications, Sound, Power, Display, Mouse & Touchpad, Keyboard, Printers, Removable Media, Date & Time, Users, Default Apps, Privacy, About) |
| File Manager | Virtual filesystem with grid/list view, search, drag-and-drop |
| Terminal | Full bash-like terminal with 50+ commands |
| System Monitor | CPU, RAM, process list in real-time |
